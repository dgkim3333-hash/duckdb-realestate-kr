01

DuckDB가 뭔가

엑셀은 100만 행에서 멈춥니다. 공시가격 한 파일이 1,558만 행입니다. 열리지도 않습니다. 그렇다고 데이터베이스 서버를 세우자니 설치·계정·포트가 따라옵니다.

DuckDB는 그 사이를 메웁니다. 실행 파일 하나를 내려받아 두 번 클릭하면 끝입니다. 데이터는 npl.duckdb 같은 파일 하나에 들어가고, 그 파일을 USB에 담아 옮기면 다른 PC에서 그대로 열립니다. 서버가 없으니 켜고 끌 것도 없습니다.

쓰는 말은 SQL입니다. "평택시 안중읍 다가구 주택 매매를 최근 1년치 뽑아 ㎡당 단가 중앙값을 내줘" 같은 걸 서너 줄로 씁니다. 1,558만 행을 훑어도 몇 초입니다.

엑셀과 갈리는 지점

엑셀은 보면서 고치는 도구이고, DuckDB는 쌓아놓고 물어보는 창고입니다. 둘은 경쟁하지 않습니다. 실제로는 DuckDB에서 조건을 걸어 200행쯤 뽑아낸 뒤, 그걸 엑셀로 열어 보는 식으로 씁니다.

02

설치 — 5분

방법 A · 실행 파일 (윈도우, 가장 쉬움)

duckdb.org/install 에서 Windows를 고르고 duckdb_cli-windows-amd64.zip을 받습니다. 압축을 풀면 duckdb.exe 하나만 나옵니다. 설치 과정이 없습니다 — 그 파일이 곧 프로그램입니다.

# 받은 폴더에서 실행 duckdb.exe # 또는 데이터 파일을 지정해서 열기 duckdb.exe C:\NPL\npl.duckdb

Microsoft Visual C++ 재배포 패키지가 필요합니다. 대부분 PC에 이미 깔려 있고, 없으면 실행할 때 알려줍니다.

방법 B · 파워셸 한 줄

powershell -NoExit iex (iwr "https://install.duckdb.org/install.ps1").Content

방법 C · 파이썬에서 쓸 사람

pip install duckdb

파이썬으로 쓰면 pandas와 바로 오갑니다. CSV를 읽어 테이블로 만들고 결과를 데이터프레임으로 받는 게 몇 줄입니다.

첫 명령 세 개

-- CSV를 읽어 테이블로 만들기 (헤더 자동 인식) CREATE TABLE 실거래 AS SELECT * FROM read_csv('C:/data/아파트매매.csv'); -- 뭐가 들어있나 보기 SELECT * FROM 실거래 LIMIT 10; DESCRIBE 실거래; -- 나가기 .quit
CSV를 미리 정리하지 않아도 됩니다

read_csv가 구분자·인코딩·컬럼 타입을 알아서 잡습니다. 한글 CSV가 깨지면 encoding='utf-8'이나 all_varchar=true를 덧붙이면 대개 해결됩니다. 파일 여러 개를 'C:/data/*.csv'처럼 한 번에 읽을 수도 있습니다.

04

어디서 받나

전부 무료이고 회원가입만 하면 됩니다. 경매 낙찰결과만 유료 사이트입니다.

국토교통부 실거래가 공개시스템 rt.molit.go.kr 아파트·연립다세대·오피스텔·단독다가구·상업업무용 매매/전월세. 엑셀 말고 CSV로 받을 것. 한 번에 최대 1년, 시도별로 나눠 받습니다. 유형 탭을 바꾸면 조건이 초기화되니 탭 → 매매/전월세 → 시도 순서로 설정하십시오.
공공데이터포털 data.go.kr 주택 공시가격, 건축물대장(건축HUB), 온비드 공매 결과. 파일로 받는 것과 API로 받는 것 두 가지가 있습니다. 공시가격은 파일이 3GB가 넘으니 다운로드에 시간이 걸립니다.
대법원 법원경매정보 courtauction.go.kr 매각 결과. 조회 창이 7일뿐이라 주 1회는 받아야 빠지지 않습니다. 응찰자 수는 여기 없습니다.
온비드 onbid.co.kr 캠코 공매. 압류재산·기타일반재산 등 재산 유형이 갈리고 저감 구조가 경매와 완전히 다릅니다(경매는 회차당 20~30%, 공매는 1%). 두 자료를 절대 한 표에 합치지 마십시오.
국가철도공단 레일포털 국가철도공단 자료실 · 도시광역철도 역사정보 전국 역 좌표. 환승역은 노선별로 여러 행이라 역 단위로 묶어야 합니다. 역명 끝의 "역"을 떼어내지 않으면 검색이 안 잡힙니다.
서울시 정비사업 정보몽땅 cleanup.seoul.go.kr 재개발·재건축 추진현황. 단계별 인가일이 들어 있는 파일을 받으십시오. 서울만 있고 경기도는 별도 경로입니다.
DuckDB duckdb.org/install 프로그램 본체. 현재 1.5.5.
05

실제로 쓰는 질의

동네 ㎡단가 중앙값

SELECT 법정동, count(*) AS 건수, median(거래금액 / 전용면적)::BIGINT AS ㎡단가 FROM 실거래_아파트_매매 WHERE 시군구 LIKE '%평택시%' GROUP BY 1 HAVING 건수 >= 10 ORDER BY ㎡단가 DESC;

반경 안의 역까지 거리

위도·경도만 있으면 하버사인 공식으로 직선거리가 나옵니다. 한 번 매크로로 만들어두면 그다음부터는 한 줄입니다.

SELECT 역명, 노선명, round(6371000 * 2 * asin(sqrt( pow(sin(radians(위도 - 37.0)/2), 2) + cos(radians(37.0)) * cos(radians(위도)) * pow(sin(radians(경도 - 127.0)/2), 2) ))) AS 거리m FROM 철도역 ORDER BY 거리m LIMIT 3;

유찰 횟수별 낙찰가율

SELECT 유찰횟수, count(*) AS 표본, median(매각가 * 100.0 / 감정가) AS 낙찰가율 FROM 경매낙찰_통합 WHERE 상태 = '매각' GROUP BY 1 ORDER BY 1;
겪어보고 아는 함정 셋

① 법정동코드를 리 단위로 쓰지 마십시오. 읍·면은 리마다 코드가 달라, 평택시 팽성읍 하나에 26개가 붙습니다. 그대로 조인하면 24만 행이 40만 행으로 부풀어 오릅니다.

② 파일명을 믿지 마십시오. 국토부 사이트가 과거 조회 결과를 잘못 내려주는 일이 실제로 있었습니다. 파일 안의 검색조건 머리글을 열어 시도·기간·유형을 눈으로 확인하는 게 안전합니다.

③ 단독과 다가구를 섞지 마십시오. 대지 ㎡단가가 3.8배 차이납니다. 섞어서 중앙값을 내면 감정가를 3배 넘게 틀리게 잡습니다.

06

망가뜨리지 않으려면

전부 파일 하나라는 게 장점이자 약점입니다. 그 파일이 날아가면 전부 날아갑니다. 다만 원천이 공개 데이터라 다시 받으면 복원됩니다 — 잃는 건 시간입니다.

파일 복사로 백업하려다 막히는 일이 흔합니다. 프로그램이 파일을 붙잡고 있으면 복사가 안 됩니다. 그럴 땐 EXPORT DATABASE를 쓰는 게 낫습니다. 잠금을 타지 않고, 압축돼서 훨씬 작습니다.

-- 통째로 내보내기 (2.2GB → 415MB) EXPORT DATABASE 'D:/백업/npl_20260922' (FORMAT PARQUET, COMPRESSION ZSTD); -- 되살리기 IMPORT DATABASE 'D:/백업/npl_20260922';

내보낸 폴더 안의 load.sql에는 절대 경로가 박혀 있습니다. 다른 PC에서 복원하려면 그 경로를 먼저 바꿔야 합니다. 그리고 백업은 원본과 다른 물리 디스크에 두십시오. 같은 디스크면 같이 죽습니다.

수치는 2026-09-22 기준 실측입니다. 공시가격은 매년 11월, 실거래가는 매달 갱신되므로 행수는 계속 늘어납니다.

건축물대장·실거래가의 결측률과 마스킹 비율은 원자료 자체의 한계입니다 — 단독·다가구 번지 마스킹처럼, 알고 쓰는 것과 모르고 쓰는 것의 차이가 큽니다.
